# My Notes — [IPEREPOLU EBENEZERY A]

## Key Concepts I Learned

* Security governance helps organizations enforce security standards across Azure environments.
* Azure Policy can be used to ensure resources comply with organizational and regulatory requirements.
* Resource Locks prevent accidental modification or deletion of critical resources.


## Lab / Hands-On Work
### What I did
1. Explored Azure Policy and assigned policies to enforce compliance.
2. Reviewed Resource Locks and how they protect Azure resources from accidental deletion.
3. Navigated Microsoft Defender for Cloud and examined security recommendations.
4. Checked the Regulatory Compliance Dashboard to evaluate compliance posture.

### What happened / Result
* Policies can automatically enforce compliance requirements across Azure resources.
* Defender for Cloud provides actionable recommendations to improve security posture.
* RBAC helps reduce security risks by limiting unnecessary privileges.

### Challenges I faced
* Understanding how remediation tasks automate compliance correction.
* Understanding the difference between Azure Policy enforcement and Defender for Cloud recommendations.


## My Takeaways

<!-- What was most valuable to you personally from this session? -->
* The most valuable lesson from this session was learning how governance and compliance can be enforced proactively rather than reactively. 
* The concept of implementing security controls before resources reach production was particularly insightful
