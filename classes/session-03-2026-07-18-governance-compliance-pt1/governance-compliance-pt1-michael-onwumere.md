## Key Concepts I Learned

* Security governance helps organizations enforce security standards and regulatory compliance across Azure resources.
* Azure Policy provides a way to define, assign, and enforce organizational policies to ensure Azure resources remain compliant.
* Azure Policy follows a structure that includes **Policy Definitions**, **Initiatives**, **Assignments**, and **Compliance Evaluation**.
* Role-Based Access Control (RBAC) helps enforce the principle of least privilege by assigning users only the permissions they need.
* Overprivileged access can increase security risks and should be identified and reviewed regularly using Azure security recommendations.
* Resource Locks help prevent accidental deletion or modification of critical Azure resources.
* Microsoft Defender for Cloud provides security recommendations, monitors cloud resources, identifies security risks, and offers remediation guidance to improve an organization's security posture.

## My Takeaways

This session strengthened my understanding of Azure security governance and regulatory compliance. I learned that maintaining a secure Azure environment involves more than deploying resources—it also requires enforcing policies, implementing least-privilege access through RBAC, protecting critical resources with locks, and continuously monitoring the environment using Microsoft Defender for Cloud. These governance practices help organizations maintain security, consistency, and compliance across their cloud infrastructure.
