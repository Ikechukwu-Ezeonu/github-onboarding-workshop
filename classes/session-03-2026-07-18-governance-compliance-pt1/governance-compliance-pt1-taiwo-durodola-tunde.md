### Key Concepts I Learned

This assignment covered the first three modules of the "Security Governance and Compliance" learning path. The focus was on governance, policy enforcement, security posture management, and regulatory compliance within Azure environments. 

#### Module 1: Enforce Governance with Azure Policy and Resource Locks

Key concepts learned:

- Azure Policy helps enforce organizational standards and governance requirements. 
- Policies can be assigned at Management Group, Subscription, Resource Group, and Resource levels. 
- Built-in policies provide ready-made governance controls, while custom policies support specific organizational needs. 
- Policy initiatives allow multiple policies to be managed as a single compliance requirement. 
- Resource locks help prevent accidental deletion or modification of critical resources. 

#### Module 2: Configure Security Controls and Remediate Recommendations in Defender for Cloud

Key concepts learned:

- Microsoft Defender for Cloud provides Cloud Security Posture Management (CSPM). 
- Security standards can be configured centrally to improve governance. 
- Security recommendations highlight risks and misconfigurations. 
- Governance rules can be used to assign ownership of remediation activities. 
- Azure Policy integration enables large-scale remediation of security findings. 

#### Module 3: Evaluate Regulatory Compliance in Defender for Cloud

Key concepts learned:

- Defender for Cloud includes a Regulatory Compliance dashboard for monitoring compliance posture. 
- Organizations can evaluate compliance against security and regulatory frameworks. 
- Compliance controls can be mapped to identified security recommendations. 
- Compliance reporting supports internal governance and external audit requirements. 
- Continuous compliance monitoring improves visibility and accountability.

- Continuous compliance monitoring helps organizations prepare for audits and regulatory reviews.
