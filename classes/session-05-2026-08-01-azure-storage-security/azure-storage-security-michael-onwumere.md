## Key Concepts I Learned

- Learned what an Azure Storage Account is and the different storage services it provides (Blob, Files, Queue, and Table).
- Understood storage redundancy options (LRS, ZRS, GRS, and GZRS) and how they improve data durability and availability.
- Learned about Azure Storage security features, including encryption at rest, secure transfer, Microsoft Entra ID authentication, Shared Access Signatures (SAS), and Shared Key authorization.
- Understood how Azure Policy can be used to disable Shared Key authorization and enforce secure storage configurations.

## My Takeaways

Understanding Azure Storage security is essential for protecting cloud workloads. I learned that implementing multiple security controls, such as Microsoft Entra ID authentication, secure transfer, encryption, and Azure Policy, provides a stronger defense-in-depth strategy than relying on a single security measure.
