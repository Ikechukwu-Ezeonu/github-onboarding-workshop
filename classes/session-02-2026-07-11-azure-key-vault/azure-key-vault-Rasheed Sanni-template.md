## Key Concepts I Learned

During today's session, I gained a solid understanding of Azure Key Vault and its core components, including:

Azure Key Vault – A secure service for storing and managing sensitive information such as secrets, keys, and certificates.
Secrets – How to securely store and retrieve sensitive information such as passwords, connection strings, and API keys.
Certificates – Understanding how Azure Key Vault manages digital certificates used for authentication and encryption.
Keys – Learning how cryptographic keys are created, stored, and managed to support encryption and decryption operations.
Role-Based Access Control (RBAC) – How Azure RBAC can be used to securely manage access to Azure Key Vault resources by assigning permissions based on user roles.
